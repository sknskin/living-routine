# 사용자 여정 및 화면 정보 구조

## 네비게이션

하단 **홈 / 캘린더 / 루틴 / 기록** 4탭. 공간 전환은 상단 선택 메뉴, 계정·개인 알림·공간 관리는 보조 설정 화면. 캘린더(언제?)와 타임라인(누가 무엇을?)은 별도 화면이지만 활동 상세로 연결. 홈은 내 할 일 우선이며 공간 전체 필터 제공.

## Flow U01: 신규 가입

1. 앱 실행 → 간편 로그인(최소 제공자; 실제 조합 미정).
2. 기존 초대 링크가 있으면 참여 흐름 우선. 없으면 기본 공간 제안(이름 선택 입력).
3. 추천 루틴 중 원하는 항목만 활성화(선택 0개 가능), 주기·담당자 사후 편집 가능.
4. 홈 진입 → 가볍게 구성원 초대 제안(건너뛰기 가능).
5. 알림 권한은 필요 시 맥락을 설명한 후 요청; 허용 거부해도 앱 내 기능 사용 가능.

## Flow U02: 기존 공간 초대 수락

공유 링크/코드 → 로그인 또는 기존 세션 확인 → 공간명·구성원·공유 범위 확인 → 명시적 수락 → 멤버십 생성 → 공간 홈. 초대자가 설정한 기존 루틴을 중복 생성하지 않는다. 만료·취소·재사용·중복 참여·기존 회원·권한 변경을 예외로 처리한다.

## Flow U03: 루틴 생성·편집

루틴 탭 → 추천 목록/직접 생성 → 종류(고정/완료일 기준/수동) → 일정/간격 → 담당(고정/교대/자율) → 개인 알림 선택 → 미리보기 → 저장. 설정 변경 시 현재 회차 유지가 기본, 미래 일반 회차만 재계산. 이미 개별 변경된 미래 회차는 자동 덮어쓰지 않음.

## Flow U04: 원터치 완료와 복구

홈/캘린더에서 회차 완료 → 즉시 짧은 체크 모션 → 서버 검증·확정 → 완료 목록/타임라인 갱신. 완료를 취소할 때 후속 영향이 없으면 자동 복구, 후속 회차가 이미 변경·완료되었으면 영향 확인. 다른 사용자에게 대신 수행했다면 원래 담당과 수행자를 분리한다. **권장 초안**: 본인 수행만 직접 기록하고, 타인 기록은 정정 요청.

## Flow U05: 미완료·도움 요청

현재 회차는 홈 앞쪽, 오래된 미완료는 별도 영역. 담당자가 요청 생성 → 대상자에 중요 알림 → 수락 전 담당 유지 → 수락 시 서버 검증 후 책임 변경 → 이력 기록. 건너뛰기는 완료로 집계하지 않음. 완료일 기준에서는 건너뛴 시점부터 새 간격 계산.

## Flow U06: 감사/타임라인

공간의 완료 이벤트 → 해당 구성원의 타임라인 → 고마워/수고했어 등 선택 반응 + 선택적 짧은 메시지 → 수신자의 활동 기록에 표시. 강제 반응, 미반응 재촉, 별점·벌점 없음. 혼자 쓰는 공간에서는 개인 활동 기록으로 표시.

## 접근성·빈 상태

- 큰 글꼴, 충분한 터치 영역, 스크린리더 레이블, 명확한 대비, 애니메이션 감소 설정 반영.
- 루틴 0개: 추천/직접 추가 진입; 구성원 1명: 공동 기능 강요하지 않음.
- 푸시 거부: 앱 내 알림함에서 확인. 네트워크 불량: 서버 미확정 상태를 성공처럼 표시하지 않음.

## 필수 화면 목록

로그인/초대 검증, 신규 공간, 추천 선택, 홈(필터/완료), 캘린더/날짜 상세, 루틴 목록/편집, 도움 요청, 생활 기록/상세/반응, 공간 선택/관리/초대, 개인 알림·DND/기기, 계정·탈퇴, 동기화·오류·충돌 안내.
