# 제품 요구사항(PRD)

## 비전과 배경

혼자 또는 함께 사는 사람들의 생활 루틴을 가볍게 관리하고, 서로의 수고를 알아차리고 인정하는 모바일 앱. **가전·IoT 자동 연동 없이** 앱에서 루틴·분담·알림을 처리한다. 원본 이미지의 '같이, 더 가볍게'는 콘셉트 참고, 최종 명칭 아님.

원본 대화 의도: 처음부터 기본 주기 제안, 이용자가 루틴 추가, 공동생활 분담, 장래 소모품 수수료/제휴 고려, 앱으로 프로토타입 검증. 본 문서의 다중 공간·강화된 기술 구조는 이후 1~28단계 합의로 발전한 범위.

## 대상 및 핵심 가치

- 1인 가구: 잊기 쉬운 일을 반복 규칙과 알림으로 관리.
- 커플/가족/룸메이트: 담당, 요청, 완료, 기록을 공유하고 비판·벌점 없는 감사 표현.
- 제품 원칙: 입력 최소화, 원터치 완료, 공간별 프라이버시, 알림 피로 감소, 핵심 기능 무료.

## MVP 제외 및 비목표

가전/IoT 연동, 사진 완료 인증, 점수·벌점·강제 감사, 자체 채팅 메신저, 쇼핑 탭, 상품 직접 주문/결제, 금융/ETL 기능, 복잡한 AI 자동화, 완전한 오프라인 동기화, 미확정 결제 기능. 온보딩 중 나이·성별·상세 주소 필수 수집 없음.

## 사용성/성공 검증

- 4~8명/약 2주 내부 베타. 혼자 사는 사람과 2명 이상 공간을 모두 포함.
- 관찰: 첫 루틴 생성·첫 완료, 주간 반복 이용, 공동 초대, 규칙/교대 이해, 알림 부담, 감사 기능 필요성.
- 내부 베타는 통계적 사업 성과 증명이 아닌 UX 검증. 수치 목표·출시 판단 임계값은 실제 관측 후 설정.

## 사업화 경로

MVP 무료 → 공동 구매 목록 → 소모품 관리 → 실제 제휴 수요 검증 → 고급 기능 프리미엄 검토. 상업적 링크는 사용자가 물품을 필요로 할 때만 노출; 4탭 유지. 구매 유도 푸시/완료 팝업 광고 금지.
