# 알림·실시간 동기화·다중 기기 정책

## 알림 채널

- 일정: 하루 1회 요약(개인 설정) 및 필요한 루틴만 개별 예정 알림.
- 미완료: 최초 알림 후 최대 **1회** 재알림. 완료·건너뛰기·담당 변경 시 취소.
- 협업: 도움 요청/수락, 담당자 변경 등 행동이 필요한 중요 이벤트 즉시(방해 금지와 개인/공간 설정 준수).
- 활동: 일반 완료, 감사 반응은 기본 앱 내 공유; 일반 푸시 기본 꺼짐.
- 개인 DND 및 공간별 알림 제어는 각 사용자에게만 적용. 시스템 전체 집중 모드 강제 변경 불가.

## 다중 기기

논리적인 알림 1개를 사용자별로 생성한 뒤, 활성화되어 있고 권한을 허용한 각 기기 토큰으로 전송. 기기별 수신 선택 가능. 앱 내 읽음 상태는 계정 단위로 공유하되 이미 OS에 표시된 푸시의 원격 삭제를 보장하지 않음.

## 전송 정합성

`notification_outbox`에 사용자/회차/종류/재알림 순번(요약은 공간·날짜)으로 논리적 중복 방지. 일반 알림은 시간대가 겹치면 묶기; 중요한 도움 요청은 묶음 지연 금지. 발송 직전 회차·권한·DND·기한 최신 상태 확인. Push Ticket=접수, Receipt=공급자 처리 상태, 사용자 실수신/열람과 별개.

전송 실패 유형에 따라 `429`/일시 `5xx`는 제한적 지수 백오프, 기한 초과 이벤트는 폐기, 무효 기기 토큰은 비활성화, 영구 인증 오류는 운영 알림. 무한 재시도 금지. 정확히 한 번 OS 배너 전달은 보장 불가하므로 **논리적 중복 최소화**와 **DB 업무 정합성**을 목표로 한다.

## Realtime

핵심 데이터(회차 상태, 담당·도움 요청, 주요 타임라인)를 실시간 구독. 앱 시작/포그라운드 복귀/재연결/공간 전환 시 인증·멤버십 확인 후 서버 최신 재조회. 공간별 쿼리 키·구독을 분리하며 이전 공간의 캐시와 채널 정리. 이벤트는 데이터를 직접 영구 결정하는 수단이 아니라 재조회/캐시 무효화 신호.

## 보안/프라이버시

공간 탈퇴·토큰 만료 시 RLS와 발송 대상 재검증, 민감 메시지 본문을 실시간 방송 페이로드에 최소화. 잘못된 공간 알림 딥링크 시 접근 거절 화면. 로그에 push token·초대 원문·메시지 본문 노출 방지.

## 테스트

한 계정 두 기기, 완료 직전 발송, 중복 Cron, 여러 알림 동시, DND 시작/종료, 토큰 만료, Expo Push Ticket/Receipt 처리, 포그라운드 복귀, 연결 단절/구독 갱신, 공간 탈퇴 직후 유출 검증. 오프라인 쓰기 정책은 보류.
