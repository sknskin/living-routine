# 구현 전 게이트·정합성 점검 목록

## 개발 착수 전 확인

- [ ] 사용자로부터 **명시적인 개발 착수 승인** 받음 (현재 미승인).
- [ ] 실제 저장소 경로, 기존 파일·Git 미커밋 변경, 기존 하네스 확인.
- [ ] D18 및 D22~D28 권장 초안의 기술적/법적 충돌 재점검.
- [ ] 오프라인 쓰기 보류가 각 화면/테스트/로컬 캐시에 미치는 영향 분리.
- [ ] 소셜 로그인 제공자 최소 조합과 iOS/Android 심사 요구 확인.
- [ ] Supabase 개발·내부 테스트 환경 연결/무료 제한/백업 저장 장소 확인.
- [ ] 백업·Auth·Storage 복구 범위와 개인정보 삭제 요청 처리 검증.
- [ ] 저장소 소유권, 여러 세션/에이전트 쓰기 권한 및 Slack 연결 여부 확인.
- [ ] 실기기 테스트 장치, 푸시 빌드 자격증명, 공개 배포 승인 필요성 확인.

## 사용자 합의에 부합하는 기본값

1. 직접 확정 정책을 구현 기준으로 사용한다.
2. 권장 초안은 개별 테스트/근거가 확보될 때 상세 확정하고 불일치는 로그에 남긴다.
3. 토이프로젝트 특성을 고려해 복잡한 서비스·유료 기능은 처음부터 도입하지 않는다.
4. 프라이버시·RLS·DB 상태 전이와 일정 계산은 UI 미세 개선보다 우선한다.

## 현재 미실행 작업

모바일 앱 생성, Supabase 프로젝트 연결/DDL 실행, Git 초기화/커밋, 외부 Slack 발송, 배포, 실제 시뮬레이터 테스트는 모두 **미실행**. 이 패키지는 Markdown 기획서 및 향후 개발 지침만 제공한다.
