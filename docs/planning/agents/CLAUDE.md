# Claude Code 작업용 프로젝트 지침 템플릿

> 이 파일은 기존 저장소 루트의 `CLAUDE.md`를 무조건 대체하기 위한 파일이 아니다. **개발 승인 후** 기존 하네스와 병합하고 저장소 정책에 맞게 배치한다.

1. `README.md` → `docs/00-decision-register.md` → 관련 기능 문서 → `agents/MASTER-ORCHESTRATOR.md` 순서로 읽는다.
2. 직접 확정 사항 변경 금지, `RECOMMENDED-DRAFT`는 검증 가능한 기본값, `ON-HOLD` 오프라인 쓰기 임의 구현 금지.
3. CLI에서 사용 가능한 실제 에이전트·모델·권한을 확인한 뒤 필요 시 병렬 분업. 특정 모델명을 사전 가정하지 않는다.
4. 독립 작업만 병렬화하며, DB 마이그레이션·루틴 엔진·공통 타입은 단일 변경 소유자 지정.
5. 기능 단위 DB·서버·UI·테스트 완성, `docs/09-test-plan.md`에 검증 근거 연결.
6. 사용자 승인 없는 파일/Git/DB/외부 서비스 변경은 금지. 현재 문서 작성은 개발 승인 아님.
7. 실제 실행 결과만 완료 보고, 실기기 접근 없으면 실기기 검증 완료로 표시하지 않는다.
8. Task 작성·실행은 `tasks/TASK-TEMPLATE.md` 기준. Slack 접근/채널은 실제 확인 시에만 사용.
